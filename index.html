Chat Clip Finder — Условия и политика конфиденциальности

Политика конфиденциальности

Приложение Chat Clip Finder работает на компьютере пользователя. Оно не передаёт персональные данные третьим лицам и не собирает их на своих серверах.

Для публикации видео в TikTok приложение использует официальный API TikTok (Login Kit и Content Posting API). Токен доступа и секрет приложения хранятся на устройстве пользователя в зашифрованном виде и используются только для загрузки видео, которые пользователь выбрал сам.

Пользователь может отключить TikTok в приложении в любой момент: токен будет отозван, а сохранённые данные для входа удалены.

Условия использования

Приложение предназначено для личного использования: для создания коротких нарезок из собственного контента и публикации их на аккаунте пользователя.

Пользователь сам отвечает за публикуемый контент и за соблюдение прав на него, а также правил платформ, на которые публикует.

Приложение предоставляется «как есть», без гарантий.
